# تجربة الحساب الجديدة

واجهة مستوحاة من المرجع: بطاقة شخصية كحلية، مجموعات قوائم بأيقونات وأسهم، خيارات مظهر مستديرة، بطاقات فرص بعمودين عندما تسمح الشاشة وحجم الخط، وهوية HAG الذهبية. لا توجد أرقام نشاط أو صور شخصية أو شارات تحقق تجارية وهمية.

حسابي للزائر يضم الدخول وإنشاء حساب وصفحات اللغة والمظهر والمساعدة. بعد الدخول تظهر بيانات الحساب والأمان ومساحة الشركة، وللمالك/المدير المؤهل تظهر العروض والتنبيهات. إعدادات الأمان لا تطلب بيانات جهاز أو جلسة قبل الدخول. الدخول والتسجيل والاستعادة صفحات مستقلة.

الـAPI يمنع حساب إدارة المنصة من تسجيل الدخول في تطبيق الشركات. هذه سياسة فصل صلاحيات؛ تظهر الآن رسالة واضحة. استعمل حساب شركة أو فرد مستقلًا على الهاتف. لا تحذف دور الإدارة لتجربة الهاتف. معاينة Web للتصفح فقط، والدخول الأصلي يتطلب Android/iOS وSecureStore.

تتحقق استجابة الدخول قبل تخزين الرمز، وتظهر رسائل مختلفة للبيانات الخاطئة وحساب الإدارة والشبكة. الأمان: تأكيد البريد، تغيير كلمة المرور باستخدام الحالية، والأجهزة مع تأكيد إنهاء الجلسة. تبقى جلسة الهاتف عند تغيير كلمة المرور، وتنتهي جلسات API الأخرى. تجنب إعادة تغيير كلمة المرور عشوائيًا إذا انقطع الرد؛ حاول الدخول بالجديدة أو الاستعادة.

التنبيهات داخل التطبيق تتحدث كل 20 ثانية أثناء الاستخدام دون طلبات متداخلة، وتتوقف في الخلفية وتعود عند فتح التطبيق. تطبق 429 ووقف المحاولة عند 401/403. لا تظهر أعداد حساب قديم بعد الخروج أو تبديل الشركة. القراءة تتم بفعل المستخدم؛ فتح تنبيه الرسالة يفتح غرفة التفاوض مباشرة، وفتح التنبيه يعلمه كمقروء. لا يتضمن التحديث Push عند إغلاق التطبيق أو WebSocket أو صوتًا.

## قبول على الهاتف

1. ادخل في Expo Go بحساب فرد/شركة مستقل، وليس حساب إدارة الويب. تأكد من أن EXPO_PUBLIC_API_ORIGIN هو خادم الحساب نفسه؛ حساب Docker المحلي لا يوجد تلقائيًا على Hostinger.
2. افتح حسابي ثم اللغة والمظهر؛ تحقق من بقاء التفضيلات بعد إعادة التشغيل.
3. تحقق من البريد وأجهزة الأمان. غيّر كلمة المرور باستخدام الحالية، وتأكد من فشل القديمة ونجاح الجديدة على جهاز آخر وانتهاء رمزه السابق.
4. بحسابي شركتين موثقتين، أرسل عرضًا ورسالة. افحص عداد الجرس وفتح الغرفة وتعليم التنبيه كمقروء. أخرج التطبيق للخلفية ثم عد إليه.
5. افحص شاشة صغيرة وحجم خط كبير: تعود الفرص لعمود واحد. لا ترفع أي صور/بيانات حقيقية لمجرد الاختبار دون قصد.

الفحوص الآلية تعزل قاعدة SQLite :memory:. الاختبارات والتصدير لا يعوضان تجربة هاتف فعلي. التطبيق يستخدم REST API فقط ولا يتصل بقاعدة البيانات مباشرة.
