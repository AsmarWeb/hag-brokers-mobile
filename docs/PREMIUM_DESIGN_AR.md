# واجهة HAG Brokers الجديدة

- اسم التطبيق في المنتصف، مع جرس فقط في الرأس.
- اللغة العربية/الإنجليزية والمظهر التلقائي/النهاري/الليلي في حسابي، للزوار والمستخدمين. التفضيلات تحفظ في التخزين الآمن الأصلي.
- شاشة ترحيب تعبيرية للشحن البحري والتجارة تظهر عند أول استخدام ويمكن استعادتها من حسابي؛ لا تمثل فرصة حقيقية.
- الرئيسية: تحية، صورة كبيرة، بحث، قطاعات، فرص بحرية وأحدث الفرص من API الفعلي؛ لا أسعار أو تقييمات أو شارات تحقق وهمية.
- السحب للتحديث وصور الفرص الأكبر ومعرض قابل لاختيار الصورة.
- صور ونصوص الشاشة من `/api/v1/app-config`، مع صورة محلية بديلة في حال غياب إعدادات الخادم أو فشل الصورة.
- تفاصيل الإدارة وحدودها موضحة في docs/api/MOBILE_APP_STUDIO_AR.md في مستودع Laravel.

## التحقق

```bash
npm ci
npm run check
npm run format:check
npx expo install --check
npm run api:check
npx expo start --go --clear --port 8083
```

api:check يشمل app-config، لذلك يجب نشر إضافة Laravel وترحيلها قبل هذا الفحص.

تجربة الهاتف المطلوبة: أول تشغيل ثم متابعة، حسابي: تبديل العربية/الإنجليزية وكل مظهر، إغلاق وإعادة فتح للتحقق من حفظ التفضيل، إطفاء الإنترنت لفحص صورة الترحيب المحلية، السحب للتحديث، فتح فرصة وتغيير صورة المعرض، تسجيل دخول شركتين واختبار النشر والعروض والرسائل. تصفح Web للمعاينة فقط؛ التخزين الآمن وتسجيل الدخول الأصليان يحتاجان Android/iOS.

الفحص الآلي لا يحل محل تجربة هاتف فعلي. التطبيق يتصل بالـREST API؛ لا يتصل بقاعدة البيانات مباشرة ولا يحمل مفاتيح خادم. لا تغيير في الاشتراكات أو الأذونات أو إرسال الرسائل.

الصورة assets/maritime-welcome.jpg مولدة للتطبيق من وصف: UAE container ship and yacht, Dubai port, navy sea and golden sunrise, portrait, no text/logos. الاقتراحات اللاحقة: حفظ مسودات محليًا، تنبيهات Push، روابط مباشرة إلى الفرصة/غرفة التفاوض؛ لم تضف في هذا التحديث.
