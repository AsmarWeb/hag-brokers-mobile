# Security

Do not disclose credentials in public issues. Report privately through the GitHub repository owner's private reporting channel when configured. This project has no hard-coded API/server secrets. EXPO_PUBLIC variables are public.

Use HTTPS and OS-backed native secure storage. Never copy a company owner's token into partner integrations. Private attachments and user text must not be exposed in logs, analytics or public caches. Server authorization is authoritative; UI hiding is not a permission boundary.

The initial app does not implement account deletion or store-release compliance flows. Complete a security and device review before public app distribution.
