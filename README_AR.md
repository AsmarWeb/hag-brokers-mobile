# تطبيق HAG Brokers — النسخة الأولى

مشروع React Native / Expo مستقل عن Laravel، وفق التصميم الكحلي والذهبي الذي اعتمدناه. يتصل بالـAPI الحقيقي، ولا يحتوي بيانات تجريبية ثابتة بدل بيانات السوق.

## التشغيل المحلي

استخدم Node24 وnpm. من مجلد التطبيق:

```bash
npm ci
cp .env.example .env
npm run check
npx expo install --check
npx expo start --go --clear
```

الإصدار Expo SDK58. نزّل Expo Go الموافق من https://expo.dev/go إذا كان متاحًا لهاتفك. عدم توافق Expo Go لا يعني عطلًا في التطبيق. على iOS أو عند غياب عميل متوافق استخدم Development Build:

```bash
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --profile development --platform android
npx expo start --dev-client --clear
```

استبدل android بـios عند إعداد اختبار iPhone، وفق حسابات Apple والتوقيع المطلوبة. هذه الأوامر اختيارية لتجهيز عميل تطوير؛ لم تُنشأ خدمة مدفوعة أو حزمة APK/IPA أو حساب Expo أو عملية نشر تلقائيًا. المصدر ليس ملف APK. يوجد eas.json لملفات development وpreview وproduction، لكن يلزم ربطه بمشروعك أنت.

لـAndroid APK تجريبي، بعد ربط حسابك ومشروعك: `npx eas-cli@latest build --profile preview --platform android`.

## ما يعمل في هذه النسخة

- السوق الحقيقي: بحث، قطاعات، صفحات، تفاصيل وصور ومواصفات بحرية.
- حساب فرد أو شركة، دخول وخروج، تأكيد البريد وإعادة إرسال الرابط واستعادة كلمة المرور، وإدارة الأجهزة.
- مساحة الشركة وحدود الخطة الفعلية؛ لا اشتراكات تجريبية أو تحصيل جديد.
- نشر فرصة بمراحل وبطاقات، مع صور وفيديو ومراجعة قبل النشر.
- تعديل العنوان والوصف والملاحظات الخاصة وإغلاق الفرصة مع revision الحالية، دون تغيير المالية أو الملكية أو الحجب.
- عروض RFQ، مرفقات خاصة، عروض مرسلة/مستلمة، اختيار/رفض/سحب بتأكيد وسبب وversion.
- غرفة تفاوض تتحدث كل8ثوانٍ أثناء ظهورها، وتتوقف في الخلفية. القراءة لا تُسجل إلا بزر التأكيد. رسائل نصية فقط دون WebSocket أو Push.
- تنبيهات RFQ والحجب الإداري المدعومة، خاصة بالمستخدم وشركته الحالية.
- عربية/إنجليزية ومظهر فاتح/داكن. محتوى الفرص الذي يكتبه المستخدم لا يترجم تلقائيًا.

## أمان الدخول والعمليات

الرمز في Expo SecureStore على Android/iOS فقط، منفصل حسب نطاق API. لا كلمات مرور محفوظة ولا رموز في روابط أو Logs أو AsyncStorage. معاينة الويب للتصفح فقط؛ تسجيل الدخول مخصص للهاتف.

الرمز لا يُرسل إلى الروابط العامة أو نطاق خارجي؛ المرفقات تُنزّل برأس Authorization ثم إلى ملف cache خاص مؤقت. المشاركة تفتح نافذة النظام باختيار المستخدم، وتحذف النسخة المؤقتة بعد إغلاقها.

يحفظ النموذج مفتاح طلب النشر/العرض/الرسالة خلال بقائه مفتوحًا؛ عند انقطاع غير مؤكد لا يغير الطلب بصمت. لا يُحفظ نموذج الكتابة بعد قتل التطبيق، لذلك افحص سجل الشركة قبل بدء طلب جديد بعد انقطاع أو إعادة تشغيل. لا إعادة إرسال خلفية تلقائية.

إغلاق التطبيق أو تسجيل الخروج يزيل عرض بيانات الحساب من الواجهة. تسجيل الخروج دون شبكة يمسح الرمز محليًا، وقد يبقى الرمز على الخادم حتى الإبطال من جهاز آخر أو انتهاء الصلاحية. تحقق من ذلك ضمن خطة الأمان قبل الإطلاق العام.

## ما لم يكتمل بعد

هذه نسخة تطوير أولى. يلزم فحص فعلي على Android/iPhone؛ ليست جاهزة لمتاجر التطبيقات بعد. لم تُختبر عمليات دخول أو نشر أو دفع حقيقية على حسابك من بيئة التطوير هنا.

إشعارات Push، الروابط العميقة بعد تأكيد البريد، حذف الحساب، تحرير ملف الشركة الكامل، إدارة/إضافة وسائط لفرصة قائمة، مقارنة العروض في شاشة مخصصة، عرض سجل القرارات، كل الحقول البحرية/التجارية المتقدمة، العمل دون إنترنت، والمدفوعات داخل التطبيق لاحقًا.

نموذج الإنشاء يغطي الأنواع التجارية الشائعة والمعلومات الأساسية واليخوت/القوارب. تستمر الخدمات الحالية في رفض تجاوز الحصة أو تعديل بيانات غير مسموحة. الحقول المتقدمة غير المعروضة يمكن إدارتها من الموقع حسب قواعده، دون اختراع صلاحيات جديدة.

## فحص الهاتف المطلوب

1. افتح السوق باللغتين وفي المظهرين وعلى هاتف ضيق؛ تحقق من الخط العربي والاتجاه وظهور الصور.
2. ادخل بشركة تجريبية مؤكدة البريد؛ أغلق التطبيق وأعد فتحه ثم جرّب الخروج والأجهزة.
3. جرّب طلب التأكيد واستعادة كلمة المرور وتحقق من وصول البريد دون إرسال كلمات المرور أو الرموز في المحادثة.
4. أنشئ فرصة مقصودة من المراحل الخمس، وصورة وفيديو ضمن20MB. جرّب الطلب الثاني لتأكيد حد الخطة المجانية ثم أغلق الفرصة إذا لم تعد تحتاجها.
5. من شركة تجريبية ثانية قدم عرض RFQ على طلب شراء، وأضف PDF/صورة خاصة، وافحص منع شركة ثالثة من الوصول.
6. تبادل الرسائل، غادر الشاشة وضع الهاتف في الخلفية، ثم عد وافحص عدم التكرار وحالة القراءة الصريحة.
7. افصل الشبكة أثناء إرسال مقصود؛ أعد الطلب دون تغيير وتحقق من عدم وجود نسخة أخرى. لا تستخدم سجلات مالية فعلية.
8. جرّب عميلًا/عضوًا عاديًا وشركة معلقة لتأكيد منع الإدارة. لا تضع حساب مسؤول المنصة في التطبيق؛ الـAPI يمنعه.
